Dustline Yard — a round-based tactical FPS in three.js. Vipers attack, Jackals defend a desert freight yard: buy weapons between rounds, plant the charge on site A or B, and out-aim five bots across up to 15 rounds. Single-player against bots, static files, no build step, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
